# 标准化足球数据库项目说明

## 项目概述

这是一个**完全独立**的项目，用于建立标准化的足球基础数据参考库。

### 核心目标

从 football-data.org API 获取并维护标准化的足球名称表，包括：
- 🌍 **国家/地区** (272个)
- 🏆 **联赛信息** (13个主要国际联赛)
- ⚽ **球队信息** (331支球队)
- 👥 **球员信息** (9,757名球员)
- 👔 **教练信息**

### 重要特点

✅ **只包含静态参考数据** - 不包含比赛、比分等动态数据  
✅ **完全独立** - 与 zqgetdata 项目无任何关联  
✅ **标准化命名** - 提供国际标准的球队和球员名称  
✅ **定期更新** - 可通过 sync_data.py 脚本同步最新数据

## 数据说明

### 数据来源

- **API**: football-data.org v4
- **认证**: X-Auth-Token (免费账户)
- **速率限制**: ~10次/分钟

### 数据内容

#### 1. 国家/地区 (countries.json)
- ID、名称、代码、国旗URL
- 父区域信息（如：Europe, Asia等）
- 共272个

#### 2. 联赛 (leagues.json)
- ID、名称、代码、类型
- 所属国家、徽章URL
- 当前赛季信息
- 共13个主要国际联赛

#### 3. 球队 (teams_with_players.json)
每支球队包含：
- **基本信息**: ID、全称、简称、三字缩写、队徽
- **详细信息**: 成立年份、场馆、官网、颜色、地址
- **所属联赛**: league_code
- **教练信息**: 姓名、国籍、合同期限
- **球员阵容**: 平均约30名球员/队

每名球员包含：
- ID、姓名（全名、姓、名）
- 出生日期、国籍
- 位置、球衣号码

#### 4. 数据统计
- 总球队数: 331支
- 总球员数: 9,757名
- 平均每队: 29.5名球员

## 使用方法

### 1. 首次获取数据

```bash
cd standard_football_db
python sync_data.py
```

这将：
- 获取所有国家/地区数据
- 获取所有联赛数据
- 逐个联赛获取球队和球员数据
- 自动处理速率限制（每次请求间隔6秒）
- 保存JSON文件到 data/ 目录

### 2. 更新数据

定期运行 `sync_data.py` 以获取最新数据：
- 球队转会信息
- 球员阵容变化
- 教练变更
- 新赛季信息

### 3. 查看数据

所有数据以JSON格式存储在 `data/` 目录：
```bash
# 查看摘要
cat data/summary.json

# 查看特定联赛的球队
# 需要使用JSON工具解析 teams_with_players.json
```

## 应用场景

### 1. 球队名称标准化

将不同来源的球队名称映射到标准名称：
```
"阿森纳" -> "Arsenal FC" (ID: 57)
"枪手" -> "Arsenal FC" (ID: 57)
"Arsenal" -> "Arsenal FC" (ID: 57)
```

### 2. 球员信息查询

快速获取球员的标准信息：
- 标准姓名拼写
- 国籍
- 位置
- 所属球队

### 3. 联赛级别识别

通过联赛代码识别比赛级别：
- PL: 英超（顶级）
- ELC: 英冠（第二级）
- CL: 欧冠（欧洲顶级）

### 4. 数据校验参考

作为其他数据源的校验参考：
- 验证球队名称是否正确
- 检查球员信息是否准确
- 确认联赛归属

## 技术细节

### API端点

- `/areas` - 获取所有国家/地区
- `/competitions` - 获取所有竞赛
- `/competitions/{code}/teams` - 获取指定联赛的球队

### 数据格式

所有数据使用JSON格式存储，便于：
- 跨平台使用

## 常见问题

**Q: 为什么不包含比赛数据？**  
A: 本项目专注于静态参考数据，比赛数据是动态的，不适合用作标准化名称表。

**Q: 如何与现有的zqgetdata项目集成？**  
A: 目前保持独立，未来可以通过API或数据映射的方式对接。

**Q: 数据多久更新一次？**  
A: 建议每周或每月更新一次，具体取决于需求。

**Q: 可以获取更多联赛吗？**  
A: 免费账户仅限13个联赛，如需更多需要付费升级。
