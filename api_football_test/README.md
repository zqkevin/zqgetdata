# API-Football 测试项目

## 项目说明

这是一个**完全独立**的测试项目，用于评估 API-Football 的数据覆盖范围和质量。

## API信息

- **名称**: API-Football
- **版本**: v3
- **网址**: https://www.api-football.com/
- **免费层级**: 每月100次请求
- **付费层级**: $15/月起（更高限额）
- **覆盖范围**: 900+联赛

## ⚠️ 使用前必读

### 需要配置API Key

此脚本需要有效的API Key才能运行。

**获取步骤**:
1. 访问 https://www.api-football.com/
2. 注册免费账户
3. 在Dashboard获取API Key
4. 编辑 `test_api_football.py`，将API Key填入:
   ```python
   API_KEY = "your_actual_api_key_here"
   ```
